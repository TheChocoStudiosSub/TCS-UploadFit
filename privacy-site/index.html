Privacy
Policy.

Your files stay yours. This page explains how TCS UploadFit handles images, local preferences and basic technical information across its Windows application and separate web demo.

✓

Privacy at a glance

The Windows Store edition processes selected images locally on your device. Image contents are not sent to a remote image-processing server, and an account is not required to use the app.

01

Images and exported files

The Windows Store edition reads the image files you select and processes them locally in the app. Image contents are not sent to a remote image-processing server. The app does not intentionally overwrite your source files. A prepared file is saved only when you choose an export action. Temporary image data and previews are held in memory while the app is open.

02

Local settings

The app stores your language choice and named image presets in local WebView2 storage on your device. It does not store copies of source images or prepared images as an account or cloud backup.

03

Accounts, analytics and advertising

The Windows Store edition does not require an account, collect payment details, include an advertising SDK, or use an analytics or tracking service. An internet connection is not required for the image-preparation workflow after the app and Microsoft Edge WebView2 Runtime are installed.

04

Microsoft Edge WebView2 Runtime

The Windows host uses Microsoft Edge WebView2 Runtime to display the application files packaged with the app. TCS UploadFit does not use the runtime to upload or process images on a remote server.

05

Separate web demo

The hosted web demo serves static application files. Its hosting provider may process basic request information, such as IP address, browser user-agent and request time, in server logs. The demo does not send selected image contents to the application host. It may cache application files for offline page loading; selected image contents are not added to that cache.

06

Data retention and deletion

Image files exported by the app are saved to the location you choose and remain under your control. You can delete those files using your device's file manager. Local language settings and presets can be cleared through the app's local site-data controls or by resetting the app's local data in Windows.

07

Children's privacy

TCS UploadFit is a general-purpose image utility. The Windows Store edition does not knowingly collect personal information from children.

08

Changes to this policy

This policy may be updated if the app's features or privacy practices change. The revised version will be published on this page.

09

Contact

For privacy questions or concerns, contact The Choco Studios through the official support page.

Terjemahan
01

File gambar dan hasil ekspor

Edisi Microsoft Store membaca dan memproses gambar yang Anda pilih secara lokal di aplikasi. Isi gambar tidak dikirim ke server pemrosesan gambar jarak jauh. Aplikasi tidak sengaja menimpa file sumber. File hasil disimpan hanya ketika Anda memilih tindakan ekspor. Data gambar sementara dan pratinjau berada di memori selama aplikasi terbuka.

02

Pengaturan lokal

Aplikasi menyimpan pilihan bahasa dan preset gambar bernama di penyimpanan WebView2 lokal pada perangkat. Salinan gambar sumber atau hasil tidak disimpan sebagai cadangan akun atau cloud.

03

Akun, analitik, dan iklan

Edisi Microsoft Store tidak memerlukan akun, tidak mengumpulkan detail pembayaran, tidak menyertakan SDK iklan, serta tidak menggunakan layanan analitik atau pelacakan. Koneksi internet tidak diperlukan untuk alur persiapan gambar setelah aplikasi dan Microsoft Edge WebView2 Runtime terpasang.

04

Microsoft Edge WebView2 Runtime

Host Windows menggunakan Microsoft Edge WebView2 Runtime untuk menampilkan file aplikasi yang disertakan dalam paket. TCS UploadFit tidak menggunakan runtime tersebut untuk mengunggah atau memproses gambar di server jarak jauh.

05

Demo web terpisah

Demo web menyajikan file aplikasi statis. Penyedia hosting dapat memproses informasi permintaan dasar, seperti alamat IP, user-agent browser, dan waktu permintaan dalam log server. Demo tidak mengirim isi gambar yang dipilih ke host aplikasi. Cache dapat menyimpan file aplikasi untuk pemuatan halaman offline, tetapi tidak menyimpan isi gambar yang dipilih.

06

Penyimpanan dan penghapusan data

File hasil ekspor disimpan di lokasi yang Anda pilih dan tetap berada dalam kendali Anda. Anda dapat menghapusnya melalui pengelola file perangkat. Pengaturan bahasa dan preset lokal dapat dihapus melalui kontrol data lokal aplikasi atau dengan mengatur ulang data lokal aplikasi di Windows.

07

Privasi anak

TCS UploadFit adalah utilitas gambar untuk penggunaan umum. Edisi Microsoft Store tidak secara sadar mengumpulkan informasi pribadi dari anak-anak.

08

Perubahan kebijakan

Kebijakan ini dapat diperbarui jika fitur atau praktik privasi aplikasi berubah. Versi terbaru akan dipublikasikan di halaman ini.

09

Kontak

Untuk pertanyaan atau masalah terkait privasi, hubungi The Choco Studios melalui halaman dukungan resmi.
