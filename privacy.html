Privacy

TCS UploadFit prepares image files on your device. The Windows Store edition does not upload the images you select.

Images and exports

The Store edition reads the files you select and processes them in the local app. Image contents are not sent to an image-processing server. The app does not intentionally overwrite the source file. A prepared file is saved only when you choose an export action. Temporary image data and previews are held in memory while the app is open.

Local settings

The app stores your language choice and named image presets in local WebView2 storage on this device. It does not store a copy of the source images or prepared images as an account or cloud backup.

Accounts, analytics and advertising

The Store edition does not require an account, collect payment details, include an advertising SDK, or use an analytics or tracking service. No network connection is required for the image-preparation workflow after the app and WebView2 Runtime are installed.

Windows WebView2 Runtime

The Windows host uses Microsoft Edge WebView2 Runtime to display the packaged application files. The runtime is a Windows component. TCS UploadFit does not use it to upload or process images on a remote server.

Web demo

The separate hosted demo serves static application files. Its hosting provider may process basic request information, such as IP address, browser user-agent and request time, in server logs. The demo does not send selected image contents to the application host. The demo may cache application files for offline page loading; selected image contents are not added to that cache.

Privasi

TCS UploadFit menyiapkan file gambar di perangkat Anda. Edisi Microsoft Store tidak mengunggah gambar yang Anda pilih.

Gambar dan hasil ekspor

Edisi Store membaca file yang Anda pilih dan memprosesnya di aplikasi lokal. Isi gambar tidak dikirim ke server pemrosesan gambar. Aplikasi tidak sengaja menimpa file sumber. File hasil hanya disimpan saat Anda memilih tindakan ekspor. Data gambar sementara dan pratinjau berada di memori selama aplikasi terbuka.

Pengaturan lokal

Aplikasi menyimpan pilihan bahasa dan preset gambar bernama di penyimpanan WebView2 lokal pada perangkat ini. Aplikasi tidak menyimpan salinan gambar sumber atau hasil sebagai cadangan akun atau cloud.

Akun, analitik, dan iklan

Edisi Store tidak memerlukan akun, mengumpulkan detail pembayaran, menyertakan SDK iklan, atau menggunakan layanan analitik dan pelacakan. Koneksi internet tidak diperlukan untuk alur persiapan gambar setelah aplikasi dan WebView2 Runtime terpasang.

Windows WebView2 Runtime

Host Windows menggunakan Microsoft Edge WebView2 Runtime untuk menampilkan file aplikasi yang sudah dikemas. Runtime tersebut merupakan komponen Windows. TCS UploadFit tidak menggunakannya untuk mengunggah atau memproses gambar di server jarak jauh.

Demo web

Demo terpisah yang dihosting menyajikan file aplikasi statis. Penyedia hosting dapat memproses informasi permintaan dasar, seperti alamat IP, user-agent browser, dan waktu permintaan dalam log server. Demo tidak mengirim isi gambar yang dipilih ke host aplikasi. Demo dapat menyimpan cache file aplikasi untuk pemuatan halaman offline; isi gambar yang dipilih tidak dimasukkan ke cache tersebut.
