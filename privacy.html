Privacy Policy

TCS UploadFit prepares image files on your device. The app does not send selected image content to TCS or to an image-conversion server.

Images and metadata

Your browser reads, decodes, resizes and encodes the selected images locally. Original files are not overwritten. Exported files are generated on your device. Source EXIF metadata is not intentionally copied to the output.

Local settings

Your language selection and saved presets may be kept in local browser storage. They are not synchronized to TCS.

Hosting and request logs

The website is delivered by its hosting provider. Like other website hosts, the provider may automatically process technical request and security logs, which can include an IP address, request time, requested path, user-agent, referrer when sent, HTTP status and response timing. These are hosting and operational records, not uploads of the image files selected for local processing. Log access and retention are governed by the hosting provider's policies and configuration.

Network activity

The app downloads its page, interface code and updates from the hosting origin. Image processing does not use a remote image-processing API, analytics SDK or advertising SDK.

Children

TCS UploadFit is a general-purpose utility and is not designed to collect personal information from children.

Changes and contact

This policy may change when the app or its hosting arrangement changes. For privacy questions, contact thechocostudio@gmail.com.

Kebijakan Privasi

TCS UploadFit menyiapkan file gambar langsung di perangkat Anda. Aplikasi tidak mengirimkan isi gambar yang dipilih ke TCS atau ke server konversi gambar.

Gambar dan metadata

Browser membaca, mendekode, mengubah ukuran, dan mengodekan gambar secara lokal. File asli tidak ditimpa. File hasil dibuat di perangkat Anda. Metadata EXIF dari file sumber tidak sengaja disalin ke file hasil.

Pengaturan lokal

Pilihan bahasa dan preset tersimpan dapat disimpan di penyimpanan lokal browser. Data tersebut tidak disinkronkan ke TCS.

Hosting dan log permintaan

Situs dikirimkan melalui penyedia hosting. Seperti penyedia situs lainnya, penyedia hosting dapat memproses log teknis dan keamanan secara otomatis, yang dapat mencakup alamat IP, waktu permintaan, jalur halaman yang diminta, user-agent, referrer apabila dikirim browser, status HTTP, dan waktu respons. Catatan tersebut merupakan log operasional hosting, bukan unggahan file gambar yang dipilih untuk diproses secara lokal. Akses dan masa penyimpanan log mengikuti kebijakan serta konfigurasi penyedia hosting.

Aktivitas jaringan

Aplikasi mengunduh halaman, kode antarmuka, dan pembaruan dari origin hosting. Pemrosesan gambar tidak menggunakan API pemrosesan gambar jarak jauh, SDK analitik, ataupun SDK iklan.

Anak-anak

TCS UploadFit merupakan utilitas umum dan tidak dirancang untuk mengumpulkan informasi pribadi anak-anak.

Perubahan dan kontak

Kebijakan ini dapat berubah apabila aplikasi atau pengaturan hosting berubah. Untuk pertanyaan privasi, hubungi thechocostudio@gmail.com.
